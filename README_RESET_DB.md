# Сброс тестовой БД и чистая миграция `api`

Этот патч нужен, если база тестовая и можно начать заново.

## Что входит

- `backend/api/models.py` — актуальные модели, включая правильные статусы 1С.
- `backend/api/onec_services.py` — витрины/импорт используют новые статусы.
- `reset_test_db.py` — удаляет тестовую SQLite БД, удаляет старые миграции приложения `api`, создаёт одну новую миграцию и применяет её.
- `reset_test_db.bat` — запуск скрипта на Windows двойным кликом или из терминала.

## Правильные статусы 1С в коде

- `Принято на склад БП/СП`
- `Передано в лабораторию`
- `Принято в лаборатории`
- `Передано из лаборатории`
- `Выполнено / готово к выдаче`
- `Выдан заказчику`
- `Другой статус`

Импорт также распознаёт старую формулировку `Принято в лабораторию`, но сохраняет её внутренне как `Принято в лаборатории`.

## Как применить

1. Остановите проект через `Ctrl+C`.
2. Скопируйте файлы из архива в корень проекта `warehouse-dashboard` с заменой.
3. Запустите:

```bat
cd C:\Users\User\Desktop\warehouse-dashboard
reset_test_db.bat
```

или вручную:

```bat
cd C:\Users\User\Desktop\warehouse-dashboard
backend\.venv\Scripts\python.exe reset_test_db.py
```

После этого можно запускать проект обычным стартовым скриптом.

## Важно

Скрипт удаляет:

- `backend/db.sqlite3`
- старые файлы `backend/api/migrations/000*.py`
- кэш `backend/api/migrations/__pycache__`

Медиа-файлы и загруженные картинки он не удаляет.
